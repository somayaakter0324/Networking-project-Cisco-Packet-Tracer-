Computer Networking Projects & Practical Labs
This repository contains my computer networking projects, Packet Tracer
practice files, and individual lab exercises completed using Cisco
Packet Tracer.

The repository is a collection of separate networking tasks. Each .pkt
file may focus on a specific topic or configuration, rather than being
part of one complete project.
Repository Contents
The Packet Tracer files cover different networking concepts and
practical configurations, including:
1. IP Addressing and Subnetting
- IPv4 address configuration
- Classful addressing
- Classless addressing (CIDR)
- FLSM (Fixed Length Subnet Mask)
- VLSM (Variable Length Subnet Mask)
- Subnet and host calculations
2. Routing
- Static Routing
- RIP version 1 (RIPv1)
- RIP version 2 (RIPv2)
- OSPF
- Routing configuration and connectivity testing
3. Switching
- VLAN configuration
- Switch and end-device connectivity
- Inter-VLAN communication, where included in a lab
4. Network Services
- Router-based DHCP configuration
- Server-based DHCP configuration
- DNS server configuration
- Web server configuration
5. NAT and Network Connections
- Static NAT configuration
- Serial DCE/DTE connections
- Clock-rate configuration
- Copper Cross-Over Ethernet connections
Featured Project: Airport Network Management System
One of the larger projects in this repository is an Airport Network
Management System designed and simulated using Cisco Packet Tracer.

The topology connects 10 airport departments:
1. Passenger Check-in & Ticketing
2. Security
3. Airline Offices
4. Baggage Handling
5. Server Room
6. Cargo Management
7. Administration
8. Accounts & Finance
9. HR / Staff
10. Flight Operations
The Server Room includes: - DNS Server - Airport Website (Web Server) -
Test Server

The airport project demonstrates network design, subnetting, routing,
VLANs, DHCP, DNS, Web Server, Static NAT, and serial/Ethernet
connections as configured in the topology.
Tools Used
- Cisco Packet Tracer
- Simulated Cisco routers and switches
- Simulated PCs, laptops, and servers
Purpose
The purpose of this repository is to document and organize my hands-on
learning in computer networking, from basic IP addressing and subnetting
to routing protocols, VLANs, network services, and larger network design
projects.
How to Use
1. Download or clone this repository.
2. Open a .pkt file using Cisco Packet Tracer.
3. Explore the topology and device configurations for each individual
   exercise.
Note: This repository contains multiple separate labs and projects.
Not every topic listed above is implemented in every Packet Tracer file.
Check each file to see which concepts and configurations it
demonstrates.
